# 10.0 정비주기 및 특별점검 기준

## 10.1 기본 정비주기

Globe Valve, 즉 글로브 밸브의 정기 분해정비, 즉 Overhaul 주기는 설비 중요도 등급에 따라 차등 적용한다.

본 표의 정비주기는 RAG 판정 및 CMMS 경보 생성을 위한 사내 기준값으로 사용한다. 단, 제작사 IOM, 법정검사 기준, 설비별 예방정비 기준, 운전 조건이 더 엄격한 경우에는 해당 기준을 우선 적용한다.

정비주기는 다음 방식으로 계산한다.

**정비 만료일 = 마지막 분해정비일 + 중요도 등급별 분해정비 주기**

정비 만료일이 기준일보다 이전이면 “정비 주기 초과”로 판정한다.

| 중요도 등급 | 대표 설비                         | 분해정비 주기 | 외관·작동 점검 주기 |
| ----------- | --------------------------------- | ------------: | -------------------: |
| A등급       | 터빈 윤활유, 주증기 계통 차단밸브 |        12개월 |                3개월 |
| B등급       | 보조 계통 제어·차단밸브          |        24개월 |                6개월 |
| C등급       | 저압 또는 비상시 동작 밸브        |        36개월 |               12개월 |

본 문서 기준에서 A등급 밸브의 기본 분해정비 주기는 12개월로 설정한다.

단, 누설, 조작 불량, 반복 고장 이력이 있는 경우에는 정비주기가 남아 있더라도 특별점검을 우선 적용한다.

---

## 10.2 특별점검 착수 기준

다음 중 하나라도 해당하면 정기 주기와 관계없이 특별점검을 수행한다.

1. 밸브 시트 누설 발생
2. 그랜드패킹부 누설 발생
3. 밸브 개폐 토크가 평소보다 20% 이상 증가
4. 밸브 조작 중 이상 소음 또는 진동 발생
5. 유량 조절이 원활하지 않거나 제어성이 저하됨
6. 장기간, 즉 6개월 이상 미사용 후 재가동
7. 동일 부위 누설 또는 고장이 최근 12개월 내 2회 이상 반복됨

최근 12개월 내 동일 부위 이상이 2회 이상 확인되면 **반복 고장**으로 분류한다.

반복 고장으로 분류된 부위는 다음 정비 시 우선 점검 대상으로 지정한다.

동일 부위 판단 예시는 다음과 같다.

* 그랜드패킹부 누설
* 보닛-바디 체결부 누설
* 시트 누설
* 스템 나사산 손상
* 디스크 및 시트 접촉 불량
* 플랜지부 누설
* Pressure Seal 부위 누설

위 항목은 각각 별도 부위로 분류한다. 예를 들어 그랜드패킹부 누설 1회와 시트 누설 1회는 동일 부위 반복 고장으로 분류하지 않는다.

---

## 10.3 분해정비 시 우선 점검 순서

분해정비 착수 시 기본 우선 점검 순서는 다음과 같다.

1. 그랜드패킹
2. 스템
3. 디스크 및 시트
4. 보닛 가스켓
5. 체결 볼트 및 너트류

단, 최근 누설 또는 반복 고장 이력이 있는 부위가 있으면 해당 부위를 최우선으로 점검한다.

예를 들어, 그랜드패킹부 누설이 최근 12개월 내 2회 이상 확인된 경우에는 일반 점검 순서보다 그랜드패킹부를 먼저 확인한다.

## 11.2 그랜드패킹 교체 판단 기준

그랜드패킹부 누설 이력이 있거나 동일 부위 이상이 반복된 경우, 그랜드패킹은 교체 검토 대상이다.

단, 최종 교체 여부는 분해 후 실측 점검으로 확정한다.

다음 중 하나라도 해당하면 그랜드패킹을 신품으로 교체한다.

1. 패킹 경화 확인
2. 패킹 마모 또는 찢김 확인
3. 패킹 고착 확인
4. 스터핑박스 내면 긁힘 또는 편마모 확인
5. 스템 패킹 접촉부 손상 확인
6. 그랜드너트 조임 후에도 누설 재발 가능성이 높다고 판단됨
7. 패킹 압축 여유가 남아 있지 않음

그랜드패킹 교체 시 패킹 이음부는 패킹 개수에 따라 엇갈리게 배열한다.

* 2개 구성: 180도
* 3개 구성: 120도
* 4개 구성: 90도

그랜드패킹 배열 기준은 제작사 IOM 또는 사내 정비기준이 있는 경우 해당 기준을 우선 적용한다.

# 12.0 Globe Valve 특화 점검 기준

Globe Valve는 디스크가 시트에 수직으로 눌리며 유량을 조절하거나 차단하는 구조이다.

따라서 Gate Valve와 달리 디스크와 시트 접촉 상태, 스템 상하 이동 상태, 중간 개도에서의 진동 여부를 중요하게 확인해야 한다.

다음 항목을 추가 점검한다.

1. 디스크와 시트 접촉면의 편마모 여부
2. 시트 접촉면의 침식, 패임, 스크래치, 캐비테이션 여부
3. 디스크가 시트 중심에 정확히 안착되는지 여부
4. 스템 작동 시 디스크가 편심 없이 상하 이동하는지 여부
5. 개폐 시 과도한 조작 토크 또는 걸림 현상 여부
6. 중간 개도에서 진동 또는 소음 발생 여부
7. 반복 개폐가 많은 밸브의 스템 나사산 마모 여부

Globe Valve는 유량 조절 과정에서 중간 개도 운전이 발생할 수 있으므로, 중간 개도 상태에서의 진동, 소음, 캐비테이션, 제어성 저하 여부를 별도로 확인한다.

# 13.0 점검 결과 판정 기준

분해 후 점검 결과는 다음 3등급으로 판정하여 CMMS, 즉 정비관리시스템에 등록한다.

| 판정        | 정의                                                        | 후속 조치                                            |
| ----------- | ----------------------------------------------------------- | ---------------------------------------------------- |
| 정상        | 모든 점검 항목이 기준 이내이며 누설 또는 미조치 사항이 없음 | 정상 운전 복귀                                       |
| 조건부 정상 | 작동은 가능하나 일부 항목의 재점검 또는 추적 관찰이 필요함  | Open Point 등록 후 운전 가능. 차기 점검 시 우선 확인 |
| 불량        | 작동 불가, 누설 지속, 주요 부품 교체 필요                   | 정비 완료 전 운전 복귀 불가                          |

“조건부 정상”은 운전 자체가 불가능한 상태는 아니지만, 정비 이력상 주의해야 할 항목이 남아 있는 상태를 의미한다.

조건부 정상 판정 시에는 반드시 Open Point, 즉 미결 조치 항목을 등록해야 한다.

조건부 정상 예시는 다음과 같다.

1. 현재 누설은 없으나 최근 12개월 내 동일 부위 누설 이력이 2회 이상 있음
2. 작동은 가능하나 조작 토크가 이전 점검 대비 증가함
3. Blue Check 결과 경미한 편접촉이 있으나 래핑 후 운전 가능 수준으로 개선됨
4. 부품 교체 필요성은 낮으나 차기 정비 시 재확인이 필요함
5. 현장 조건상 즉시 조치하지 못한 경미 결함이 있음

## 13.1 스템 점검 기준

스템은 다음 4개 항목을 점검한다.

1. 균열 또는 침식 여부
2. 나사산 손상 여부
3. 패킹 접촉부 마모 또는 손상 여부
4. 스템 휨 여부

4개 항목이 모두 기준 이내일 때 스템 상태를 정상으로 판정한다.

다음 중 하나라도 해당하면 스템은 보수 또는 교체 검토 대상으로 분류한다.

1. 육안상 균열 또는 침식이 확인됨
2. 나사산 손상으로 원활한 개폐가 어려움
3. 패킹 접촉부에 과마모, 스크래치, 부식이 확인됨
4. 스템 휨으로 디스크가 시트 중심에 정확히 안착되지 않음

---

## 13.2 디스크 및 시트 접촉 상태 판정

디스크와 시트의 접촉 상태는 Blue Check로 확인한다.

Blue Check, 즉 접촉청색 검사 또는 Contact Pattern Check는 디스크와 시트 접촉면에 청색 표시제를 얇게 도포한 뒤 접촉 흔적을 확인하여 접촉 균일성, 편마모, 국부 접촉 여부를 판정하는 방법이다.

판정 기준은 다음과 같다.

1. 접촉 상태가 균일하면 정상으로 판정한다.
2. 접촉 불량 시 래핑을 수행한다.
3. 손상이 심하면 육성용접 후 선반가공을 검토한다.
4. 균열이 의심되면 PT, 즉 침투탐상검사를 수행한다.
5. 래핑 후에도 접촉 불량이 지속되면 손상 정도에 따라 재래핑, 육성용접 후 가공, Seat Ring 보수, 디스크 교체 또는 시트 교체를 검토한다.
6. 균열이 의심되는 경우에는 PT 등 비파괴검사 결과를 우선 반영한다.

래핑 후에도 접촉 불량이 지속되고 보수로 복구가 어렵다고 판단되면 불량으로 판정한다.

# 14.0 누설 점검 및 조치 기준

## 14.1 누설 점검 부위

성능시험 또는 분해정비 시 다음 부위의 누설 여부를 확인한다.

1. 그랜드패킹부
2. 보닛-바디 체결부
3. 밸브 시트부
4. 배관 연결 플랜지부
5. Pressure Seal 부위

누설 점검 결과는 누설 부위, 누설 형태, 누설량, 발생 조건, 조치 결과를 정비기록서에 기록한다.

---

## 14.2 누설 부위별 조치 기준

| 누설 부위          | 1차 조치                                      | 2차 조치                                                                |
| ------------------ | --------------------------------------------- | ----------------------------------------------------------------------- |
| 그랜드패킹부       | 그랜드너트를 좌우 균등하게 소량씩 번갈아 조임 | 패킹 재점검 또는 교체, 스템 패킹 접촉부 손상 확인, 스터핑박스 내면 확인 |
| 보닛-바디 체결부   | 보닛 볼트 체결 토크 재확인                    | 보닛 가스켓 신품 교체                                                   |
| 시트부             | Blue Check로 접촉 상태 확인                   | 래핑 후 복구 불가 시 디스크 또는 시트 보수·교체                        |
| 플랜지부           | 가스켓 및 체결 상태 확인                      | 가스켓 교체 후 체결 토크 재확인                                         |
| Pressure Seal 부위 | 접촉면, 가스켓 상태, 체결 상태 확인           | Pressure Seal 가스켓 교체 또는 제작사 기준에 따른 보수                  |

그랜드패킹부 누설은 Globe Valve에서 흔히 발생하는 누설 유형이다.

최근 12개월 내 그랜드패킹부 누설 또는 미세 비침이 2회 이상 확인되면 반복 고장으로 분류하고, 패킹 교체를 우선 검토한다.

그랜드너트는 좌우 균등하게 소량씩 번갈아 조인다. 과도한 조임은 스템 작동 불량, 조작 토크 증가, 패킹 손상을 유발할 수 있으므로 조임 후 밸브 개폐 상태와 누설 여부를 함께 확인한다.

---

# 15.0 체결 및 조립 관리 기준

## 15.1 체결 토크 관리 대상

다음 부위는 체결 토크를 관리해야 한다.

1. 보닛 볼트 및 너트
2. 요크 볼트
3. 구동모터 고정볼트
4. 마운팅베이스 볼트
5. 그랜드너트
6. 플랜지 체결 볼트

체결 토크값은 제작사 IOM, 사내 정비기준, 작업오더에 명시된 값을 우선 적용한다.

적용 토크값이 불명확한 경우 현장 정비책임자의 확인 후 작업한다.

---

## 15.2 체결 방법

체결 시 다음 기준을 따른다.

1. 제작사 기준 또는 사내 정비기준의 토크값을 적용한다.
2. 편하중이 생기지 않도록 대각선 방향으로 단계적·균등하게 조인다.
3. 나사부에는 윤활제를 도포하여 부식과 고착을 방지한다.
4. 플랜지 볼트는 너트 위로 나사산 3산 정도 나오게 한다.
5. 좌우 또는 상하 여유길이를 동일하게 맞춘다.
6. 체결 후 Match Mark 정합 여부를 확인한다.
7. 체결 후 누설 여부와 밸브 개폐 상태를 확인한다.

볼트 체결 시 한쪽으로 편중하여 조이면 보닛-바디 체결부, 플랜지부, Pressure Seal 부위에 편하중이 발생할 수 있으므로 단계적이고 균등한 체결을 원칙으로 한다.

---

## 15.3 그랜드패킹 체결 및 배열 기준

그랜드너트는 다음 시점에 나누어 상태를 확인하고 필요 시 조정한다.

1. 조립 완료 시
2. 일정 시간 경과 후
3. 계통 연결 전
4. 성능시험 또는 누설 확인 시

양쪽 그랜드너트는 좌우 균등하게 소량씩 번갈아 조인다.

과도한 조임은 스템 작동 불량, 조작 토크 증가, 패킹 손상을 유발할 수 있으므로 조임 후 밸브 개폐 상태와 누설 여부를 함께 확인한다.

그랜드패킹 이음부 배열 기준은 다음과 같다.

* 2개 구성: 180도
* 3개 구성: 120도
* 4개 구성: 90도

Yarn Packing, 즉 편조 패킹과 Mold Packing, 즉 성형 패킹을 혼용할 경우에는 제작사 또는 사내 정비기준에 따른다.

별도 기준이 있는 경우 편조 패킹을 상·하부에 배치하고 성형 패킹을 중간에 배치할 수 있다.

# 17.0 정비 단계 및 체크리스트

분해정비 작업오더는 다음 6단계로 진행한다.

| 단계 | 단계명                        | 핵심 작업                                                                       |
| ---: | ----------------------------- | ------------------------------------------------------------------------------- |
|    1 | 분해 전 준비                  | 전원 차단, Red Tag 확인, 배관 배수, Match Mark 표시, 공기구 준비, 작업구역 설정 |
|    2 | 구동모터 또는 액추에이터 분해 | 밸브 개도 상태 확인, Match Mark 기록, 고정볼트 분해                             |
|    3 | 밸브 몸체 분해                | 보닛 분해, 디스크·스템 인출, 그랜드패킹 제거                                   |
|    4 | 분해 후 점검                  | 스템 4항목 점검, 디스크 및 시트 Blue Check, PT, 판정 등급 결정                  |
|    5 | 조립                          | 신품 가스켓·패킹 적용, 토크 관리, 윤활 도포                                    |
|    6 | 성능시험 및 마무리            | Red Tag 반납, 누설 점검, 작동 상태 확인, 정비기록 등록                          |

Globe Valve 주의사항은 다음과 같다.

구동모터 또는 액추에이터 분해 전 밸브 위치는 제작사 IOM, 사내 정비절차서, 해당 작업오더의 지시에 따른다.

별도 지시가 없는 경우에는 현장 정비책임자의 확인 후 기준 위치를 설정하고, 분해 전 밸브 개도 상태와 액추에이터-밸브 Match Mark를 반드시 기록한다.

Globe Valve는 Gate Valve와 구조 및 작동 방식이 다르므로 Gate Valve의 개도 기준을 임의로 적용하지 않는다.

---

## 17.1 단계 1 — 분해 전 준비 체크리스트

1단계 분해 전 준비에서는 다음 항목을 확인한다.

* 전원 차단 확인
* Red Tag, 즉 작업금지 또는 격리 표지 확인
* 배관 배수 확인
* 잔압 제거 확인
* Match Mark 표시
* 보닛-바디 플랜지 간격 측정
* 공기구 준비
* 작업구역 설정
* 고소작업 여부 확인
* 개구부 또는 추락 위험 확인
* 작업허가서 및 안전조치 확인
* 주변 배관, 구조물, 케이블 간섭 여부 확인

Match Mark와 보닛-바디 플랜지 간격 측정은 조립 시 원위치 복원과 체결 상태 확인에 필요한 기준값이므로 반드시 기록한다.

Red Tag가 적용된 설비는 정비책임자의 확인 없이 임의로 조작하거나 반납해서는 안 된다.

---

## 17.2 단계 2 — 구동모터 또는 액추에이터 분해 체크리스트

2단계 구동모터 또는 액추에이터 분해에서는 다음 항목을 확인한다.

* 제작사 IOM 또는 작업오더상 밸브 개도 기준 확인
* 분해 전 밸브 개도 상태 기록
* 액추에이터-밸브 Match Mark 표시
* 전원 차단 및 제어신호 차단 확인
* 구동모터 고정볼트 상태 확인
* 분해 중 낙하 또는 회전 위험 확인
* 분해 후 임시 보관 위치 확인

구동모터 또는 액추에이터 분해 전 밸브 위치는 제작사 IOM, 사내 정비절차서, 작업오더 지시를 우선 적용한다.

별도 지시가 없는 경우 현장 정비책임자의 확인 후 작업한다.

---

## 17.3 단계 3 — 밸브 몸체 분해 체크리스트

3단계 밸브 몸체 분해에서는 다음 항목을 확인한다.

* 보닛 볼트 및 너트 분해
* 보닛-바디 체결부 상태 확인
* 디스크 및 스템 인출
* 그랜드패킹 제거
* 보닛 가스켓 제거
* Pressure Seal 구조인 경우 Pressure Seal 가스켓 상태 확인
* 분해 부품 식별표 부착
* 분해 부품 손상 방지 조치

분해한 가스켓과 패킹은 재사용 여부를 임의 판단하지 않고, 본 지침 및 제작사 IOM 기준에 따라 교체 또는 폐기한다.

---

## 17.4 단계 4 — 분해 후 점검 체크리스트

4단계 분해 후 점검에서는 다음 항목을 확인한다.

* 스템 4항목 점검
* 디스크 및 시트 Blue Check
* 균열 의심 부위 PT
* 스터핑박스 내면 확인
* 그랜드패킹 상태 확인
* 디스크 및 시트 접촉면 확인
* 캐비테이션, 침식, 패임, 스크래치 확인
* 볼트 및 너트 나사산 상태 확인
* 점검 판정 등급 등록

점검 결과는 정상, 조건부 정상, 불량 중 하나로 판정한다.

조건부 정상 판정 시 Open Point를 반드시 등록한다.

---

## 17.5 단계 5 — 조립 전 점검 체크리스트

5단계 조립 전에는 다음 항목을 확인한다.

* 배관 내부 세척 확인
* 부품 표면 스크래치 확인
* 신품 가스켓 준비 확인
* 신품 패킹 준비 확인
* Pressure Seal 가스켓 준비 또는 상태 확인
* 나사부 윤활 도포
* 그랜드패킹 이음부 배열각 확인
* Match Mark 정합 확인
* 체결 토크값 확인
* 제작사 IOM 특이사항 확인

조립 전에는 분해 전 기록한 Match Mark, 플랜지 간격, 밸브 개도 상태를 재확인한다.

---

## 17.6 단계 6 — 성능시험 및 마무리 체크리스트

6단계 성능시험 및 마무리에서는 다음 항목을 확인한다.

* 밸브 개폐 상태 확인
* 그랜드패킹부 누설 확인
* 보닛-바디 체결부 누설 확인
* 시트 누설 확인
* 플랜지부 누설 확인
* Pressure Seal 부위 누설 확인
* 구동모터 또는 액추에이터 작동 상태 확인
* 조작 토크 또는 작동 전류 이상 여부 확인
* Red Tag 반납 조건 확인
* 정비기록서 작성
* Open Point 등록 또는 종결 여부 확인

성능시험 결과 이상이 없고 정비책임자 확인이 완료된 경우에만 운전 복귀를 검토한다.

# 18.0 Open Point 관리 기준

정비 중 즉시 조치하지 못했거나 추적 관찰이 필요한 항목은 Open Point로 등록한다.

Open Point 등록 대상은 다음과 같다.

1. 조건부 정상 판정 항목
2. 반복 누설 또는 반복 고장 의심 항목
3. 차기 점검 시 우선 확인이 필요한 항목
4. 부품 교체 여부를 추후 확인해야 하는 항목
5. 현장 조건상 즉시 조치하지 못한 항목
6. 작업 공간, 고소작업, 개구부 등 안전상 추가 확인이 필요한 항목
7. 제작사 기준 확인 후 최종 판단해야 하는 항목

Open Point에는 다음 정보를 기록한다.

* Open Point 번호
* 관련 설비
* Tag No.
* 발생 부위
* 내용
* 발생 작업오더
* 조치 예정일
* 담당 부서
* 종결 여부
* 종결 조건
* 관련 정비기록 번호
* 차기 점검 우선순위

조건부 정상으로 판정된 경우에는 반드시 Open Point를 등록해야 한다.

Open Point는 조치 결과가 정비기록에 등록되기 전까지 종결하지 않는다.

Open Point 종결 조건은 다음 중 하나 이상을 만족해야 한다.

1. 부품 교체 완료
2. 누설 재점검 결과 이상 없음
3. 성능시험 결과 이상 없음
4. 차기 점검에서 동일 이상 미발생 확인
5. 정비책임자 또는 담당 부서의 종결 승인 완료

# 19.0 작업 공간 및 안전 판단 기준

## 19.1 작업 공간 기준

Globe Valve 분해정비 시 설비 중심 기준 약 2m 작업 반경 확보를 권장한다.

단, 2m는 작업성 판단을 위한 권장 기준이며, 실제 작업 가능 여부는 부품 인양 공간, 작업자 자세, 주변 배관 간섭, 비상 대피 동선, 고소작업 여부를 종합하여 판단한다.

작업 공간이 부족한 경우 다음 위험이 발생할 수 있다.

1. 공구 사용 간섭
2. 부품 분해 및 인양 어려움
3. 작업자 자세 불안정
4. 인접 배관 또는 구조물 손상
5. 비상 시 대피 동선 부족

작업 공간이 2m 기준에 미달하면 작업 가능 여부를 조건부로 판단하고, 보호 조치 또는 보조 작업자 배치를 검토한다.

작업 공간이 부족한 경우 다음 조치를 검토한다.

* 인접 장애물 임시 제거
* 보조 작업자 배치
* 소형 공구 또는 특수 공구 사용
* 인양 장비 사용 가능 여부 확인
* 임시 작업발판 설치
* 작업구역 출입 통제
* 작업순서 변경

---

## 19.2 고소작업 판단 기준

작업 위치 또는 조작부 높이가 2m 이상이면 고소작업으로 분류한다.

고소작업 판단 및 안전조치는 산업안전보건 관련 법규, 발주처 안전기준, 사내 안전작업허가 기준 중 더 엄격한 기준을 우선 적용한다.

고소작업 시 다음 안전조치를 적용한다.

1. 작업발판 설치
2. 안전난간 설치
3. 안전대 착용
4. 발판 고정 상태 확인
5. 하부 출입 통제
6. 추락 위험 구역 표시
7. 개구부 덮개 또는 난간 설치

분해, 인양, 체결, 토크 작업이 필요한 경우 작업발판 없이 사다리만 사용하여 작업하는 것은 원칙적으로 금지 또는 제한 대상으로 판단한다.

단, 최종 판단은 현장 안전작업허가 기준에 따른다.

---

## 19.3 개구부 및 추락 위험 기준

작업구역 주변에 바닥 개구부, 난간 미설치 구역, 단차, 발판 미고정 구역이 있으면 추락 위험으로 분류한다.

개구부가 확인된 경우 다음 조치를 수행한다.

1. 개구부 덮개 설치
2. 안전난간 설치
3. 출입 제한 표시
4. 작업자 안전대 착용
5. 작업발판 설치 위치 재검토
6. 하부 통제 구역 설정

개구부 또는 추락 위험이 해소되지 않은 상태에서는 분해정비 착수를 제한하고, 안전관리자 또는 정비책임자의 확인 후 작업한다.

---

## 19.4 작업 공간 및 안전 관련 RAG 판단 기준

AI 챗봇은 Walkinside 공간데이터, 작업오더, 설비 위치정보를 근거로 다음 항목을 판단할 수 있다.

1. 작업 반경 2m 확보 여부
2. 주변 배관 또는 구조물 간섭 여부
3. 조작부 높이 2m 이상 여부
4. 고소작업 해당 여부
5. 개구부 또는 추락 위험 존재 여부
6. 작업발판 필요 여부
7. 하부 출입 통제 필요 여부

단, AI 챗봇의 판단은 사전 검토용이며 최종 작업허가 여부는 현장 안전관리자 또는 정비책임자의 승인을 따른다.

# 20.0 정비기록 작성 기준

정비 완료 후 다음 항목을 정비기록서에 기록한다.

1. 설비명
2. Tag No.
3. 절차서 No.
4. 정비일자
5. 작업자, 확인자, 입회자
6. 분해 전 이상상태
7. 누설 발생 부위
8. Stem 점검 결과
9. Disc & Seat Blue Check 결과
10. PT 검사 결과
11. 디스크 및 시트 래핑 여부
12. 교체 부품명
13. 가스켓 교체 여부
14. 그랜드패킹 교체 여부
15. Pressure Seal 가스켓 확인 또는 교체 여부
16. 적용 토크값
17. 조립 후 밸브 개폐 상태
18. 성능시험 결과
19. 점검 판정 등급
20. Open Point 등록 내역
21. 작업 공간 및 고소작업 확인 결과
22. 특이사항 및 후속 조치

정비기록은 향후 반복 고장 분석, 정비주기 산정, 부품 교체 판단, Open Point 종결 판단의 근거로 사용된다.

정비기록 작성 시 다음 원칙을 따른다.

1. 판단 결과뿐만 아니라 판단 근거를 함께 기록한다.
2. “정상”, “조건부 정상”, “불량” 판정 사유를 명확히 작성한다.
3. 교체하지 않은 부품도 재사용 판단 근거를 기록한다.
4. 반복 고장 여부 판단에 필요한 과거 이력을 함께 연결한다.
5. Open Point가 있는 경우 종결 조건과 조치 예정일을 함께 기록한다.
6. 작업 공간 또는 안전상 제약이 있었던 경우 해당 내용을 기록한다.

# 21.0 AI 챗봇 답변 기준

AI 챗봇은 본 문서를 근거로 다음 유형의 답변을 제공할 수 있다.

1. 정비주기 초과 여부 판단
2. 반복 고장 여부 판단
3. 부품 교체 필요성 검토
4. 점검 결과 등급 판단 지원
5. Open Point 등록 필요성 판단
6. 작업 단계별 체크리스트 제공
7. 작업 공간 및 고소작업 위험 검토
8. 최근 정비 이력 기반 후속 조치 제안

AI 챗봇은 다음과 같은 표현을 사용할 수 있다.

* “본 추가지침 기준으로는 특별점검 대상입니다.”
* “최근 12개월 내 동일 부위 이상이 2회 이상 발생했으므로 반복 고장으로 분류할 수 있습니다.”
* “조건부 정상 판정 시 Open Point 등록이 필요합니다.”
* “최종 교체 여부는 분해 후 실측 점검 및 정비책임자 확인으로 확정해야 합니다.”
* “작업 위치가 2m 이상이면 고소작업으로 분류되며 작업발판, 안전난간, 안전대 등 안전조치가 필요합니다.”

AI 챗봇은 다음과 같이 단정적으로 답변해서는 안 된다.

* “무조건 운전 가능합니다.”
* “무조건 교체해야 합니다.”
* “현장 확인 없이 작업해도 됩니다.”
* “안전조치 없이 진행해도 됩니다.”
* “제작사 IOM 확인 없이 본 지침만 따르면 됩니다.”

부품 교체, 운전 복귀, 안전작업 허가, Open Point 종결 여부는 현장 정비책임자 또는 안전관리자의 최종 확인을 따른다.

# 22.0 용어 정의

본 문서에서 사용하는 주요 용어는 다음과 같다.

| 용어          | 정의                                                                              |
| ------------- | --------------------------------------------------------------------------------- |
| Globe Valve   | 디스크가 시트에 수직으로 눌리며 유량을 조절하거나 차단하는 밸브                   |
| CMMS          | Computerized Maintenance Management System, 즉 정비관리시스템                     |
| Open Point    | 즉시 조치하지 못했거나 추적 관찰이 필요한 미결 조치 항목                          |
| Red Tag       | 작업 중 임의 조작을 방지하기 위한 작업금지 또는 격리 표지                         |
| Blue Check    | 디스크와 시트 접촉면에 청색 표시제를 도포하여 접촉 상태를 확인하는 검사           |
| PT            | Penetrant Testing, 즉 침투탐상검사                                                |
| IOM           | Installation, Operation and Maintenance Manual, 즉 제작사 설치·운전·정비 매뉴얼 |
| Overhaul      | 설비를 분해하여 주요 부품을 점검, 보수, 교체하는 분해정비                         |

| 스터핑박스    | 그랜드패킹이 삽입되는 공간                                                        |
| 래핑          | 디스크와 시트 접촉면을 연마하여 밀봉성을 회복하는 작업                            |
| Match Mark    | 분해 전 부품 위치를 표시하여 조립 시 원위치 복원을 돕는 기준 표시                 |
| Pressure Seal | 내부 압력을 이용해 밀봉력을 확보하는 보닛 밀봉 구조                               |

# 23.0 RAG 인용 예시

AI 챗봇 답변 시 다음과 같이 인용할 수 있다.

예시 1.

> 최근 12개월 내 동일 부위 누설이 2회 이상 확인되면 반복 고장으로 분류합니다. 따라서 해당 그랜드패킹부 누설 이력은 반복 고장 검토 대상입니다.
> 근거: 절차-표준-018 추가지침 §10.2

예시 2.

> 조건부 정상은 운전은 가능하나 추적 관찰이 필요한 상태를 의미합니다. 조건부 정상 판정 시 Open Point 등록이 필요합니다.
> 근거: 절차-표준-018 추가지침 §13.0, §18.0

예시 3.

> Globe Valve의 디스크 및 시트 접촉 상태는 Blue Check로 확인하며, 접촉 불량 시 래핑을 수행합니다. 래핑 후에도 불량이 지속되면 보수 또는 교체를 검토합니다.
> 근거: 절차-표준-018 추가지침 §13.2

예시 4.

> 작업 위치 또는 조작부 높이가 2m 이상이면 고소작업으로 분류하며, 작업발판, 안전난간, 안전대 등 안전조치가 필요합니다.
> 근거: 절차-표준-018 추가지침 §19.2

예시 5.

> 구동모터 또는 액추에이터 분해 전 밸브 위치는 제작사 IOM, 사내 정비절차서, 작업오더 지시를 우선 적용해야 합니다. Gate Valve의 개도 기준을 Globe Valve에 임의 적용해서는 안 됩니다.
> 근거: 절차-표준-018 추가지침 §17.0, §17.2
