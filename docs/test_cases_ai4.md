## 5. 분기 주의 케이스 (3차 vs 4차)

| 프롬프트 | 올바른 분기 | 헷갈리는 분기 | 구분 포인트 |
|---|---|---|---|
| 그랜드패킹을 교체해야 해? | 4차 (교체 검토) | 3차 (이력) | 판단 동사(해야) |
| 보닛 가스켓 교체 이력 있어? | 3차 (가스켓 이력) | 4차 (교체) | "교체 이력"=조회 |
| 정비 주기 지났어? | 4차 (주기 초과) | 3차 | "주기" |
| 최근 정비 이력 보여줘 | 3차 (이력) | 4차 | "이력"만, 주기/예정일 없음 |

## 6. 검증 방법

1. `index.html`을 연다 (브랜치 `feature/ai-maintenance-cycle`).
2. 예시 버튼(주기초과/다음예정일/우선부품/교체검토) 또는 위 프롬프트 입력 → Send.
3. 확인 포인트:
   - **3 챗봇 응답**: `ANSWER` + `grounded` 배지 + 출처 라인
   - **2 API 흐름**: HTTP 요청 → `CMMS·정비주기 DB` 조회 단계 → HTTP 응답
   - **4 AI 응답 JSON**: `grounded`, `sources`, `retrieval` 포함
   - 주기 초과 답변이 현재 날짜 기준으로 동적 계산되는지
