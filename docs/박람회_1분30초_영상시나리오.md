# i3DWEB AI Assistant 박람회 영상 시나리오

## 1. 영상 개요

- **영상 길이:** 약 1분 25초
- **영상 목적:** 현장 작업자가 겪는 정보 탐색과 판단의 불편함을 보여주고, i3DWEB AI Assistant가 3D 설비·정비 이력·절차서·실시간 모니터링을 하나의 업무 흐름으로 연결하는 모습을 전달한다.
- **핵심 메시지:** `찾는 시간은 줄이고, 현장 판단은 빠르고 정확하게.`
- **주요 대상:** 발전소·플랜트 운영 담당자, 정비 작업자, 설비 관리자, 의사결정자
- **권장 형식:** 16:9, 1920×1080, 화면 녹화와 현장 연출 영상 혼합
- **전체 분위기:** 초반은 답답하고 복잡하게, AI Assistant 등장 이후에는 빠르고 명확하게 전환

## 2. 전체 구성

| 구간 | 시간 | 내용 |
|---|---:|---|
| 문제 제기 | 0:00~0:16 | 문서 탐색, 시스템 전환, 현장 판단의 어려움 |
| AI Assistant 등장 | 0:16~0:22 | i3DWEB 안에서 자연어로 업무 시작 |
| 기능 시연 | 0:22~1:14 | 점검 브리핑, 정비 이력, 3D 단면 절차, RAG, 실시간 모니터링 |
| 효과 및 마무리 | 1:14~1:25 | 업무 효과와 핵심 메시지 |

---

## 장면 #1. 흩어진 문서와 반복되는 검색

- **시간:** 0:00~0:07
- **화면:** 작업자가 책상 위에 펼쳐진 여러 정비 절차서와 출력물을 넘긴다. PC 화면에는 PDF 문서와 정비 이력 시스템이 여러 창으로 열려 있다.
- **연출:** 빠르게 문서를 넘기는 손, 검색창에 여러 키워드를 반복 입력하는 모습, 필요한 내용을 찾지 못해 멈추는 장면을 짧게 교차 편집한다.
- **내레이션:**

  > 현장 작업자는 점검 전에 여러 문서와 시스템을 오가며 필요한 정보를 직접 찾아야 합니다.

- **화면 자막:**

  > 흩어진 정비 문서 · 반복되는 정보 검색

- **음향:** 종이 넘기는 소리, 키보드 입력음. 차분하지만 다소 답답한 분위기.

## 장면 #2. 현장에서 부족한 즉시 지원

- **시간:** 0:07~0:16
- **화면:** 작업자가 현장 설비 앞에서 태블릿과 출력물을 번갈아 확인한다. 장비 위치, 최근 정비 기록, 점검 기준을 각각 따로 확인하는 모습을 보여준다.
- **연출:** 화면을 분할해 `3D 설비 화면`, `정비 이력`, `PDF 절차서`, `모니터링 화면`이 서로 분리되어 있음을 강조한다.
- **내레이션:**

  > 현장에서는 어떤 장비를 먼저 점검해야 하는지, 과거에 어떤 문제가 있었는지, 지금 상태가 무엇을 의미하는지 즉시 설명해 줄 지원이 부족합니다.

- **화면 자막:**

  > 위치 · 이력 · 절차 · 상태 정보가 서로 분리

## 장면 #3. i3DWEB AI Assistant 등장

- **시간:** 0:16~0:22
- **화면:** 어두웠던 화면이 밝아지며 i3DWEB 전체 화면이 나타난다. 오른쪽 AI Assistant 입력창에 커서가 활성화된다.
- **사용자 입력:**

  > 오늘 점검할 거 알려줘.

- **내레이션:**

  > 이제 i3DWEB AI Assistant가 작업자의 점검 업무를 하나의 흐름으로 연결합니다.

- **화면 자막:**

  > i3DWEB AI Assistant

- **전환:** 질문 전송과 동시에 음악의 템포를 높인다.

## 장면 #4. 오늘의 점검 브리핑과 3D 위치 이동

- **시간:** 0:22~0:33
- **화면:** AI가 오늘 점검 대상 TAG와 점검 사유를 안내한다. 동시에 3D 뷰어가 지정된 장비 위치로 이동하고 장비를 강조한 뒤 카메라가 부드럽게 확대된다.
- **주요 동작:**

  1. 오늘의 우선 점검 대상 표시
  2. 지정 장비 TAG 선택
  3. 장비 위치로 카메라 이동
  4. `ZOOM IN` 및 강조 표시

- **내레이션:**

  > 오늘 점검할 장비와 우선순위를 브리핑하고, 해당 설비의 위치로 즉시 이동합니다.

- **화면 자막:**

  > 오늘의 점검 대상 안내 + 3D 위치 자동 이동

## 장면 #5. 최근 정비 이력 확인

- **시간:** 0:33~0:43
- **사용자 입력:**

  > 이 장비의 최근 정비 이력 알려줘.

- **화면:** 현재 선택된 장비 TAG를 기준으로 최근 정비일, 작업 유형, 교체 부품, 반복 이상, 미조치 사항이 정리되어 나타난다.
- **연출:** 최근 정비 이력과 반복 이슈에 차례로 하이라이트를 준다. 사용자가 TAG를 다시 입력하지 않아도 현재 장비를 이해한다는 점을 보여준다.
- **내레이션:**

  > 현재 선택된 장비를 이해하고 최근 정비 이력과 반복된 이상 징후를 작업자에게 요약합니다.

- **화면 자막:**

  > 현재 장비 문맥 인식 · 최근 정비 이력 즉시 조회

## 장면 #6. 3D 단면과 점검 절차 연결

- **시간:** 0:43~0:54
- **사용자 입력:**

  > 이 장비 점검 절차 알려줘.

- **화면:** 3D 뷰어에서 장비 단면이 잘리며 내부 구조가 드러난다. 챗봇에는 작업 준비, 안전조치, 분해, 점검, 재조립 순서가 표시된다.
- **주요 동작:**

  1. 장비 `CLIP` 또는 단면 보기 실행
  2. 내부 점검 위치 노출
  3. 단계별 점검 절차 표시
  4. 안전 주의사항과 필수 확인 항목 안내

- **내레이션:**

  > 문서로만 보던 점검 절차를 3D 단면과 연결해, 확인해야 할 내부 위치와 작업 순서를 함께 보여줍니다.

- **화면 자막:**

  > 3D 단면과 정비 절차의 실시간 연계

## 장면 #7. 절차서 기반 상세 RAG 질의

- **시간:** 0:54~1:04
- **화면:** 아래 세 질문을 빠르게 전환하며 각 답변 카드의 핵심 부분을 보여준다.
- **상세 질문:**

  1. `원심펌프 정비 시 공구 낙하와 이물질 유입을 어떻게 방지하고, 세척제는 어떤 기준으로 사용해야 해?`
  2. `원심펌프 인양 시 와이어 거는 위치와 정비 후 수압시험 기준은?`
  3. `원심펌프 재조립 시 반드시 신품으로 교체해야 하는 소모품은?`

- **화면 강조:**

  - TCE 세척제 사용 금지
  - 아이볼트 인양 및 최고토출압력 1.5배·3분 이상 수압시험
  - O-ring, Gasket, Gland Packing, Oil Seal 신품 교체
  - 절차서 번호와 근거 문서

- **내레이션:**

  > 상세 질문에는 사내 정비 절차서와 기술 기준을 검색해, 근거와 함께 정확한 답변을 제공합니다.

- **화면 자막:**

  > 사내 절차서 기반 RAG · 근거 있는 정비 답변

## 장면 #8. 현장 사진과 실시간 모니터링 해석

- **시간:** 1:04~1:14
- **화면:** 작업자가 카메라 버튼으로 현장 모니터링 화면을 캡처하거나 터빈 사진을 첨부한다.
- **사용자 입력:**

  > 이 장비의 실시간 모니터링 정보 알려줘.

- **주요 동작:**

  1. 현장 사진 또는 화면 캡처 첨부
  2. 터빈 모니터링 화면 인식
  3. i3DWEB `MONITORING` 타입 연결
  4. Health 69.9%, 입구 온도 26C, 효율과 압력비 해석
  5. 색상 상태 지표와 상세 설명 표시
  6. 예방 점검 필요성 안내

- **내레이션:**

  > 현장 사진과 실시간 데이터를 연결해 수치의 의미를 작업자 언어로 해석하고, 필요한 점검 항목까지 제안합니다.

- **챗봇 핵심 결론:**

  > 즉시 정지가 필요한 위험 상태는 아니지만, 효율 저하와 압력 형성 부족 징후가 있어 예방 점검이 필요합니다.

- **화면 자막:**

  > 실시간 데이터 해석 · 예방 점검 판단 지원

## 장면 #9. 기대 효과와 엔딩

- **시간:** 1:14~1:25
- **화면:** 지금까지의 핵심 화면을 빠르게 다시 보여준다. `3D 위치 이동 → 정비 이력 → 단면 절차 → RAG 답변 → 실시간 모니터링` 순서로 아이콘 또는 화면이 연결된다.
- **내레이션:**

  > 찾는 시간은 줄이고, 현장 판단은 더 빠르고 정확하게. i3DWEB AI Assistant는 설비 위치부터 정비 이력, 절차서, 실시간 상태까지 작업자의 모든 점검 과정을 하나로 연결합니다.

- **최종 화면 자막:**

  > 설비 정보와 현장 판단을 하나로
  >
  > **i3DWEB AI Assistant**

- **보조 자막:**

  > 3D Digital Twin × Maintenance Data × RAG × Monitoring

- **엔딩:** i3DWEB 로고와 AI Assistant 화면을 2초간 유지한 뒤 페이드아웃한다.

## 3. 전체 내레이션 원고

> 현장 작업자는 점검 전에 여러 문서와 시스템을 오가며 필요한 정보를 직접 찾아야 합니다. 현장에서는 어떤 장비를 먼저 점검해야 하는지, 과거에 어떤 문제가 있었는지, 지금 상태가 무엇을 의미하는지 즉시 설명해 줄 지원이 부족합니다.
>
> 이제 i3DWEB AI Assistant가 작업자의 점검 업무를 하나의 흐름으로 연결합니다. 오늘 점검할 장비와 우선순위를 브리핑하고, 해당 설비의 위치로 즉시 이동합니다.
>
> 현재 선택된 장비를 이해하고 최근 정비 이력과 반복된 이상 징후를 작업자에게 요약합니다. 문서로만 보던 점검 절차를 3D 단면과 연결해, 확인해야 할 내부 위치와 작업 순서를 함께 보여줍니다.
>
> 상세 질문에는 사내 정비 절차서와 기술 기준을 검색해, 근거와 함께 정확한 답변을 제공합니다.
>
> 현장 사진과 실시간 데이터를 연결해 수치의 의미를 작업자 언어로 해석하고, 필요한 점검 항목까지 제안합니다.
>
> 찾는 시간은 줄이고, 현장 판단은 더 빠르고 정확하게. i3DWEB AI Assistant는 설비 위치부터 정비 이력, 절차서, 실시간 상태까지 작업자의 모든 점검 과정을 하나로 연결합니다.

## 4. 촬영 및 편집 가이드

### 화면 녹화 준비

- 브라우저 확대 비율과 i3DWEB 패널 크기를 촬영 전에 고정한다.
- 모든 질문과 답변이 정상 작동하는지 사전 점검한다.
- 시연 시작 전 선택 장비와 카메라 위치를 초기 상태로 복원한다.
- 사진 첨부용 `터빈 실시간사진.png`를 바로 선택할 수 있는 위치에 준비한다.
- 화면 캡처 기능을 사용할 경우 `start_ui.bat`으로 localhost 환경을 실행한다.

### 편집 원칙

- 질문 입력 과정은 1.5~2배속으로 처리하고 결과 화면은 충분히 읽을 수 있도록 유지한다.
- 3D 카메라 이동과 단면 전환은 지나치게 빠르게 자르지 않는다.
- 핵심 수치와 절차 기준에는 확대 또는 색상 하이라이트를 사용한다.
- 장면 전환마다 긴 설명을 넣기보다 `위치`, `이력`, `절차`, `RAG`, `모니터링` 키워드를 일관되게 사용한다.
- 초반 문제 장면은 저채도, AI Assistant 등장 이후는 i3DWEB 블루 색상을 중심으로 보정한다.
