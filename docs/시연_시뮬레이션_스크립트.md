# 시연 시뮬레이션 스크립트 (RAG 챗봇 발표용)

> 라이브 데모를 못 돌리는 상황(네트워크/Ollama 미가동)에서도 **그대로 읽으며 시연**할 수 있도록,
> 실제 챗봇이 반환하는 응답 흐름을 재현한 시뮬레이션 대본입니다.
> 근거 문서: `유지보수메뉴얼(절차-표준-017) Gate Valve 정비`, `(절차-표준-018) Globe Valve 정비`,
> 부속 매뉴얼 `절차-표준-018 추가지침(§10~§20: 판정·수치·교체·작업단계 기준)`, `i3dweb_사용자_요청_및_답변_예시`.
> 응답 포맷은 `docs/action_response_spec.md`(responseType / actions / grounded·sources)를 따릅니다.

---

## 발표자 가이드 (읽는 법)

각 항목은 아래 3단으로 구성됩니다. 화면은 **좌(i3DWEB 뷰어) / 우(채팅방)** + 상단 **API 흐름 패널**을 띄워두고 진행합니다.

| 표기 | 의미 |
|---|---|
| 🗣️ **사용자** | 사용자가 입력하는 자연어 |
| ⚙️ **AI 응답(JSON)** | 백엔드가 반환하는 `responseType` / `actions` (흐름 패널에 뜨는 값) |
| 🤖 **챗봇** | 사용자에게 렌더링되는 최종 답변 |
| 📄 **출처** | grounded 답변의 인용 출처(문서·섹션) — RAG가 지어내지 않았음을 증빙 |

- **responseType 3종**: `ACTION`(뷰어 조작만) / `ANSWER`(답변만) / `ANSWER_WITH_ACTION`(둘 다)
- **데이터 소스 구분**: 매뉴얼=RAG 벡터검색 / 이력·주기=CMMS DB(AI팀) / 공간=Walkinside(솔루션팀) / 작업단계=WO 워크플로(AI팀)

# Part A. 밸브 정비 매뉴얼 RAG (절차-표준-017 / 018)

> **순수 RAG 시연.** 매뉴얼 본문에 답이 분명히 있는 질문만 모았습니다. 수치형(18%, 2m, 1~3°, 3산, 180/120/90°)은 RAG 정확도를 가장 잘 보여주는 핵심 시연 항목입니다.

### A-1. 밸브 기능·개요

🗣️ **사용자** — "Gate Valve 기능하고 특징이 뭐야?"
⚙️ **AI 응답** — `ANSWER` · `MANUAL_RAG {query:"게이트 밸브 기능 특징", valveType:"gate"}`
🤖 **챗봇** —
> 게이트 밸브는 **유량 차단용**으로 폐쇄가 확실합니다. 양정이 적어 **급속 개폐에 편리**하지만, 유체 방향 변환이 두 번 일어나 **저항(유체 마찰)이 큰** 편입니다. 디스크·시트의 교체 및 정비가 용이한 구조입니다.
📄 **출처** — 절차-표준-017 Gate Valve 정비 · §5.1.1 (개요)

---

🗣️ **사용자** — "Globe Valve랑 Gate Valve 정비 절차에서 제일 다른 점 한 가지만 알려줘"
⚙️ **AI 응답** — `ANSWER` · `MANUAL_RAG {query:"구동모터 분해 시 밸브 상태", valveType:null}`
🤖 **챗봇** —
> 두 밸브의 정비 절차는 거의 동일하지만, **구동모터 분해 시 밸브를 놓는 상태**가 다릅니다.
> - **Gate Valve → 1/4 오픈** 상태
> - **Globe Valve → 완전 닫힘(Full Close)** 상태
📄 **출처** — 절차-표준-017 / 018 · §8.1.2-1 (구동모터 분해)

### A-4. 분해 절차

🗣️ **사용자** — "분해하기 전에 부품 위치 안 헷갈리게 뭘 해둬야 해?"
🤖 **챗봇** —
> **마킹(Match Mark)**을 표시해 둡니다. 조립할 때 부품을 원위치에 그대로 설치할 수 있도록 하기 위함입니다.
📄 **출처** — §8.1.1-2

🗣️ **사용자** — "자력밀봉식(Pressure Seal) 보닛은 어떻게 분해해?"

🤖 **챗봇** —
> 다음 순서로 분해합니다:
> 1. Jack-Up 볼트 너트 분해
> 2. 보닛플레이트 분해
> 3. 동(銅)봉으로 보닛 타격
> 4. 분할키 밀어내 분해 → 서포트링 분해
> 5. 보닛플레이트 가조립 후 **Jack-Up 볼트를 조여 보닛+가스켓을 분리**

# Part B. i3DWEB 사용자 요청 시나리오 (예시 PDF 기반)

> `i3dweb_사용자_요청_및_답변_예시`의 6개 카테고리 요청에 대해, **매뉴얼 근거 + 추가 데이터**를 결합한 RAG/Action 응답으로 재구성했습니다.
> 1~2번은 뷰어 조작(`ACTION`), 3~6번은 데이터/매뉴얼 근거(`ANSWER` grounded)가 중심입니다.

## 1. 설비 찾기 기능 — `ACTION` (뷰어 조작)

🗣️ **사용자** — "터빈 윤활유 펌프 찾아줘"
⚙️ **AI 응답** — `ACTION` · `SEARCH_EQUIPMENT {query:"터빈 윤활유 펌프"}`
🤖 **챗봇** — 터빈 윤활유 펌프 **3건**을 찾았습니다. 가장 가까운 설비는 **TG-LOP-001**이며, 현재 화면을 해당 위치로 이동했습니다. 속성정보를 함께 표시합니다.

🗣️ **사용자** — "이 장비 뒷면 보여줘"
⚙️ **AI 응답** — `ACTION` · `ROTATE_VIEW {direction:"back", angle:180}`
🤖 **챗봇** — 선택한 장비의 후면 방향으로 View를 전환했습니다. 장비 중심 기준으로 카메라를 **180도 회전**했습니다.

🗣️ **사용자** — "밸브가 안 보이게 꺼줘"
⚙️ **AI 응답** — `ACTION` · `HIDE_OBJECT {targetType:"TYPE", targetValue:"VALVE"}`
🤖 **챗봇** — 현재 화면에서 밸브 객체를 숨김 처리했습니다. 다시 보려면 **"밸브 다시 보여줘"**라고 입력하세요.

🗣️ **사용자** — "선택한 이 계통만 보여줘"
⚙️ **AI 응답** — `ACTION` · `ISOLATE_SYSTEM {targetValue:null}` (현재 선택 계통)
🤖 **챗봇** — 선택한 계통의 설비만 표시했습니다. 다른 계통의 배관·밸브·장비는 임시 숨김 처리했습니다.

🗣️ **사용자** — "이 구역에 있는 주요 설비 목록 보여줘"
⚙️ **AI 응답** — `ANSWER_WITH_ACTION` · `SEARCH_EQUIPMENT {query:"현재 구역 주요 설비"}`
🤖 **챗봇** — 현재 구역의 주요 설비는 **펌프 4개, 밸브 12개, 배관 라인 8개, 열교환기 1개**입니다. 목록에서 설비를 선택하면 해당 위치로 이동할 수 있습니다.

🗣️ **사용자** — "이 펌프가 연결된 계통이 뭐야?"
⚙️ **AI 응답** — `ANSWER` · `QUERY_SPATIAL`/계통 메타 조회
🤖 **챗봇** — 선택한 펌프 **TG-LOP-001**은 **터빈 윤활유 계통**에 연결되어 있습니다. 관련 P&ID와 상·하류 연결 설비도 확인할 수 있습니다.

🗣️ **사용자** — "내 주변에 있는 밸브 목록 보여줘"
⚙️ **AI 응답** — `ANSWER_WITH_ACTION` · `FIND_NEAREST {filter:"valve"}`
🤖 **챗봇** — 현재 위치 반경 **10m 이내에 밸브 5개**가 있습니다. 가장 가까운 밸브는 **GV-102A**이며 거리 약 **3.2m**입니다.

🗣️ **사용자** — "이 구역에 있는 펌프만 보여줘"
⚙️ **AI 응답** — `ACTION` · `FILTER_BY_TYPE {targetValue:"PUMP"}`
🤖 **챗봇** — 현재 구역에서 펌프 객체만 표시했습니다. 검색된 펌프는 총 **4개**이며, 나머지 설비는 숨김 처리했습니다.

## 2. 작업 위치 안내 기능 — `ACTION`

🗣️ **사용자** — "이 설비 점검 위치로 이동해줘"
⚙️ **AI 응답** — `ACTION` · `MOVE_TO_INSPECTION {targetValue:null}`
🤖 **챗봇** — 선택한 설비의 점검 위치로 이동했습니다. 작업자는 설비 전면 기준 약 **1.5m 거리**에서 점검을 수행할 수 있습니다.

# 데모 마무리 멘트 (Q&A 직전)

1. **순수 RAG(Part A)** — 매뉴얼 수치/절차를 출처와 함께 정확히 인용. 발췌에 없으면 **"지침서에서 확인되지 않습니다"**로 폴백(환각 차단).

3. **뷰어 연동(Part B 1~2)** — 자연어 → 정형 JSON Action → 뷰어 SDK 디스패치(느슨한 결합). 모델/SDK 교체에도 독립적.
