## 7. 검증 방법

1. `index.html`을 연다 (브랜치 `feature/ai-work-stage`).
2. 예시 버튼(작업단계/다음단계/체크리스트/미완료항목/누락항목) 또는 위 프롬프트 입력 → Send.
3. 확인 포인트:
   - **3 챗봇 응답**: `ANSWER` + `grounded` 배지 + 출처(작업오더(WO)/정비 절차서)
   - **2 API 흐름**: HTTP 요청 → `작업오더(WO) 워크플로` 조회 단계(AI팀) → HTTP 응답
   - **4 AI 응답 JSON**: `grounded`, `sources`, `retrieval` 포함
