| 이 밸브의 최근 정비 이력 보여줘 | 선택/기본 GV-101A | ANSWER grounded, 이력 3건 |
| TG-VLV-205 정비 이력 보여줘 | TG-VLV-205 | ANSWER grounded, 이력 2건 |

**기대 응답 필드:** `grounded:true`, `sources:[CMMS 정비이력, 정비 지침서]`, `retrieval.hitCount:3`

## 9. 검증 방법

1. `index.html`을 연다 (브랜치 `feature/ai-maintenance-rag`).
2. 예시 버튼(정비이력/분해정비일/누설이력/Open Point) 또는 위 프롬프트 입력 → Send.
3. 확인 포인트:
   - **3 챗봇 응답**: `ANSWER` + `grounded` 배지 + 답변 + **출처** 라인
   - **2 API 흐름**: HTTP 요청 → **`정비이력 DB` 조회 단계(query→records)** → HTTP 응답 (Viewer SDK 호출 없음)
   - **4 AI 응답 JSON**: `grounded`, `sources`, `retrieval` 필드 포함
   - **5 로그**: RAG/CMMS 조회 source·hitCount·출처 표시
