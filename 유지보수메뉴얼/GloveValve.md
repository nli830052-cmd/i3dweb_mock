## Globe Valve 유지보수절차서 추가 필요 항목

### 1. 권장 점검주기 / 특별점검 기준

정기점검은 설비 중요도, 운전조건, 사용빈도, 제작사 O&M Manual 및 사내 예방정비 기준에 따라 수행한다.

다음의 경우에는 정기점검 주기와 관계없이 특별점검을 수행한다.

1. 밸브 시트 누설 발생 시
2. 글랜드패킹부 누설 발생 시
3. 밸브 개폐 또는 조작 토크 증가 시
4. 밸브 조작 중 이상 소음 또는 진동 발생 시
5. 유량 조절이 원활하지 않거나 제어성이 저하된 경우
6. 장기간 미사용 후 재가동하는 경우
7. 반복적인 누설 또는 고장 이력이 있는 경우

---

### 2. 부품별 교체 / 보수 판단 기준

보닛 가스켓
- 분해 시 재사용하지 않는다.
- 분해 정비 시 신품으로 교체한다.

Pressure Seal 가스켓
- 분해 정비 시 신품 교체를 원칙으로 한다.
- 가스켓 접촉면 손상, 변형, 진원도 불량 시 교체한다.

그랜드패킹
- 분해 후 신품 교체를 원칙으로 한다.
- 패킹부 누설, 경화, 마모, 손상, 오염이 확인될 경우 교체한다.

디스크
- 접촉면 손상, 균열, 침식, 편마모가 있을 경우 보수 또는 교체한다.
- Blue Check 결과 접촉상태가 불량하고 래핑으로 복구되지 않을 경우 교체한다.

시트
- 시트 접촉면 손상, 침식, 균열, 시트 누설 발생 시 보수 또는 교체한다.
- 래핑 후에도 접촉상태가 불량할 경우 육성용접, 선반가공 또는 교체를 검토한다.

스탬
- 휨, 균열, 침식, 나사산 손상, 패킹 접촉부 과마모가 확인될 경우 교체한다.
- 스탬 작동 시 걸림, 편심, 비정상 마찰이 발생할 경우 원인을 확인하고 보수 또는 교체한다.

요크 / 패킹플랜지 / 패킹팔로워
- 변형, 균열, 부식, 편마모가 확인될 경우 보수 또는 교체한다.

볼트 / 너트
- 나사산 손상, 부식, 변형, 체결 불량이 확인될 경우 교체한다.

스터핑박스
- 내부 긁힘, 부식, 손상, 편마모가 확인될 경우 보수 또는 교체를 검토한다.

---

### 3. Globe Valve 특화 점검 항목

Gate Valve와 다르게 Globe Valve는 **디스크가 시트에 눌리면서 유량을 조절하거나 차단하는 구조**라서, 아래 항목을 따로 추가하면 좋아.

Globe Valve 특화 점검사항

1. 디스크와 시트의 접촉면 편마모 여부를 확인한다.
2. 시트 접촉면의 침식, 패임, 스크래치, 캐비테이션 손상 여부를 확인한다.
3. 디스크가 시트 중심에 정확히 안착되는지 확인한다.
4. 스탬 작동 시 디스크가 편심 없이 상하 이동하는지 확인한다.
5. 밸브 개폐 시 과도한 조작 토크 또는 걸림 현상이 없는지 확인한다.
6. 유량 조절용으로 사용되는 밸브의 경우 중간 개도 상태에서 진동 또는 소음 발생 여부를 확인한다.
7. 반복 개폐가 많은 밸브는 디스크, 시트, 스탬 나사산의 마모 상태를 중점 점검한다.

---

### 4. 누설 점검 및 조치 기준

현재 문서에는 “각부 누설여부 점검”만 있어서 구체성이 부족해.

성능시험 시 다음 부위의 누설 여부를 확인한다.

1. 그랜드패킹부
2. 보닛과 바디 체결부
3. 밸브 시트부
4. 배관 연결 플랜지부
5. Pressure Seal 부위

누설 발생 시 다음 조치를 수행한다.

1. 그랜드패킹부 누설
   - 그랜드너트를 좌우 균등하게 조인다.
   - 누설이 지속될 경우 그랜드패킹을 재점검하거나 교체한다.
   - 스탬 패킹 접촉부 손상 여부를 확인한다.

2. 보닛 체결부 누설
   - 보닛 볼트 체결상태와 토크값을 확인한다.
   - 보닛 가스켓 손상 여부를 확인한다.
   - 필요 시 가스켓을 신품으로 교체한다.

3. 시트 누설
   - 디스크와 시트 접촉상태를 Blue Check로 확인한다.
   - 접촉 불량 시 래핑을 실시한다.
   - 래핑으로 복구되지 않을 경우 디스크 또는 시트 보수/교체를 검토한다.

4. 플랜지부 누설
   - 플랜지 가스켓 상태와 체결상태를 확인한다.
   - 필요 시 가스켓을 교체하고 체결 토크를 재확인한다.

---

### 5. 토크값 관리 기준

볼트 체결 시 제작사 기준 또는 사내 정비기준에 따른 토크값을 적용한다.

토크 관리 대상은 다음과 같다.

1. 보닛 볼트 / 너트
2. 요크 볼트
3. 구동모터 고정볼트
4. 마운팅베이스 볼트
5. 그랜드너트
6. 플랜지 체결 볼트

볼트는 편하중이 발생하지 않도록 대각선 방향으로 단계적으로 균등하게 조인다.

최종 체결 후 다음 사항을 확인한다.

1. 볼트 여유길이
2. 체결 방향 균일성
3. 체결 토크값
4. 체결 후 누설 여부
5. 조립 후 밸브 작동상태

---

### 6. 이상징후별 조치 기준

밸브 개폐가 원활하지 않은 경우
- 스탬 휨 여부 확인
- 스탬 나사산 손상 여부 확인
- 디스크와 시트 간섭 여부 확인
- 구동모터 또는 마운팅베이스 조립상태 확인
- 그랜드너트 과조임 여부 확인

시트 누설이 발생한 경우
- 디스크와 시트 접촉상태 확인
- Blue Check 수행
- 래핑 실시
- 복구 불가 시 디스크 또는 시트 보수/교체 검토

그랜드패킹부 누설이 발생한 경우
- 그랜드너트 균등 조임
- 누설 지속 시 패킹 교체
- 스탬 패킹 접촉부 손상 여부 확인
- 스터핑박스 내면 손상 여부 확인

조작 토크가 증가한 경우
- 스탬 윤활상태 확인
- 나사산 손상 여부 확인
- 그랜드너트 과조임 여부 확인
- 디스크와 시트의 간섭 여부 확인

밸브 조작 중 이상 소음 또는 진동이 발생한 경우
- 디스크 고정상태 확인
- 시트 손상 여부 확인
- 유량 조절 중 캐비테이션 또는 유체 충격 가능성 확인
- 배관 지지상태 확인

---

### 7. 예비품 관리 기준

정비 전 다음 예비품을 확보한다.

1. 보닛 가스켓
2. Pressure Seal 가스켓
3. 그랜드패킹
4. 볼트 / 너트
5. 윤활제
6. 몰리코트
7. 세척제
8. 필요 시 디스크
9. 필요 시 시트
10. 필요 시 스탬

사용한 예비품은 정비기록서에 품명, 규격, 수량, 교체 사유를 기록한다.

---

### 8. 정비 후 기록 항목

정비 완료 후 다음 항목을 정비기록서에 기록한다.

1. 설비명
2. Tag No.
3. 절차서 No.
4. 정비일자
5. 작업자 / 확인자 / 입회자
6. 분해 전 이상상태
7. 누설 발생 부위
8. Stem 점검 결과
9. Disc & Seat Blue Check 결과
10. PT 검사 결과
11. 디스크 / 시트 래핑 여부
12. 교체 부품명
13. 가스켓 교체 여부
14. 그랜드패킹 교체 여부
15. 적용 토크값
16. 조립 후 밸브 개폐상태
17. 성능시험 결과
18. 특이사항 및 후속조치
